# GW5AST-138C open-flow GPIO milestone

Date: 2026-09-20

## Verified hardware result

The diagnostic image below was loaded into the Tang Console 138K over JTAG and
entered user mode with status `0x00022230`:

```text
build/gpio_probe_key1-near-vendor-open.fs
SHA-256: 26f8b7962a8b9112ab69056da017775870520e6fb14f7516095f8fd6c9798b60
```

With this image, holding the RESET button changes the status LED color and
releasing RESET changes it back. This is the first verified working GPIO path
packed through the open-source GW5AST-138C flow in this investigation.

The image is a diagnostic milestone, not yet a fully open-source result. It was
created from an Apicula-packed image with selected bottom-edge tile fuses copied
from the matching Gowin-generated GPIO oracle. The resulting main bitmap still
differs from the vendor bitmap at three positions:

```text
(1511, 12323): vendor 0, open 1
(1511, 13216): vendor 1, open 0
(1511, 13217): vendor 1, open 0
```

The matching vendor oracle is:

```text
vendor-gpio-probe/impl/pnr/vendor_gpio_probe.fs
SHA-256: 4b6c17a5243007dcabcffd8e92a7f5d202371b514b74088dbd31d2f167515aca
```

## Confirmed findings

- `AB13` is RESET and maps to `IOB89[B]`.
- `AA13` is MODE. Pressing it briefly leaves user mode and reloads the FPGA; it
  is not suitable as an ordinary test button during SRAM configuration tests.
- Gowin enables input hysteresis on the button input. Apicula's default was
  `HYSTERESIS=NONE`; making `HYSTERESIS=ON` explicit stops the open probe from
  blinking spontaneously.
- The working vendor route starts at `X89Y108/Q6`, crosses the bottom edge using
  the `E800` family of segments, branches to the direct LED output and
  `X170Y107/LUT0`, then drives the complementary LED output.
- Replacing only the local LUT/slice tile defaults did not fix the hardware.
- Replacing the remaining nearby bottom-edge/default-routing group did fix it.
  The active bisect therefore targets that 60-bit group.
- The Gowin programmer may print a trailing `Error: Error found!` after an open
  bitstream reaches 100%. A separate status-register read returning
  `0x00022230` confirms that configuration completed.

## Reproduction notes

The reference project source is in `vendor-gpio-probe/`; its `impl/` directory
is generated by Gowin EDA. Open-flow build products remain under the ignored
`build/` directory. Keep the hash above when moving or archiving the verified
image so it cannot be confused with later bisect variants.
